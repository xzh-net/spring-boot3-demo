权限管理

权限码字典 (sys_permission): 每行 = 一个可授予的 API 权限码 (如 user:read)。角色在「角色管理」页勾选绑定权限码, 经用户令牌注入生效; 「资源准入」页的端点准入行按码引用本字典, 被引用中的码不可删除。
ID 权限码 名称 能力域 所属授权范围 状态 备注 操作
暂无权限码, 点击「新增权限码」创建
说明: 令牌实际业务码 = 用户 RBAC 码 ∩ 客户端授权范围 (「授权范围」页) 展开码 — 双维交集注入, 任一维缺口即 403; 端点是否需要某个码, 在「资源准入」页把该码设为对应行的准入要求; 「所属授权范围」列显示该码被哪些粗组收编。
