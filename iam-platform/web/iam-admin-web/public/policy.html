客户端准入策略

登录边界隔离 · 管理端用户与门户端用户同库统一管理, 通过客户端角色策略防止交叉登录
client_id 名称 允许角色 状态 备注 操作
暂无客户端数据
背景：认证中心将管理端用户与门户端用户统一在 iam_identity.sys_user 中一并管理， 为避免两类人群交叉登录（管理账号误入门户端、门户账号误入管理端），为每个客户端限定 允许登录的用户角色集合，形成登录边界隔离。
规则：表中无该客户端策略行 → 默认放行；allowed_roles 为空或 * → 放行全部； 否则仅当用户业务 RBAC 角色（资源中心 sys_user_role，经 D6 内部接口获取）与允许集合有交集时放行。 角色解析失败且配置了策略时按拒绝处理（fail-closed），不因 RBAC 服务异常而误放行。
