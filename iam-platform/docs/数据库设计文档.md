# 数据库设计文档

单库 **`iam`**，MySQL 8，**16 表**，零租户。基线与全部种子的唯一权威是 [`sql/iam.sql`](../sql/iam.sql)。

| 项 | 值 |
|---|---|
| 库名 | `iam`（utf8mb4） |
| 连接 | `192.168.31.161:3306`（root，改 `server/iam-authorization-server/src/main/resources/application-{profile}.yml`） |
| Redis | `192.168.31.161:6379` db1（会话 / 令牌运行时，非持久化业务数据） |
| 基线 | `sql/iam.sql`（新库初始化唯一入口） |
| 增量升级 | `sql/migration/V6.x__*.sql`（既有 `iam` 库手动执行，不接自动迁移框架） |

## 二、关键表结构

### sys_user — 用户凭据

```text
id | user_code (业务主键, u_+32hex) | username (唯一) | password (BCrypt)
nickname | email | phone | avatar
enabled | account_non_expired | account_non_locked | credentials_non_expired
create_time | update_time
```
> 令牌 `sub` = `user_code`，全平台只认它做用户关联；无影子用户表、无标签分类列。

### sys_permission — 权限码字典（17 码）

```text
id | code (唯一, 如 user:read) | name | status (1启用/0停用) | remark | create_time | update_time
```
> 业务分类用 **`remark` 前缀** `【管理端】`/`【门户】` 表达（无 domain 列）。
> `iam_endpoint_policy.required_authority` 按字符串引用 `code`。

### sys_role / sys_user_role / sys_role_permission

```text
sys_role:          id | code (ADMIN/PORTAL/THIRD_PARTY) | name | remark
sys_user_role:     id | user_code | role_id
sys_role_permission: id | role_id | permission_id
```
> 现状：`ADMIN`→16 码（admin 域全量），`PORTAL`→1 码，`THIRD_PARTY`→0 码。

### sys_scope / sys_scope_permission — 授权范围字典

```text
sys_scope:           id | code (admin.full/portal.profile/third.profile) | name | status | remark
sys_scope_permission: id | scope_id | permission_id
```
> **只读字典**：无 domain 列（域由 `code` 前缀自表达），页面只展示，增删改走 `sql/iam.sql` 种子。

### iam_endpoint_policy — 端点准入（48 行）

```text
id | method (GET/POST/…/ANY) | path (Spring 注册模式) | required_authority (权限码或放行档)
status (1启用/0停用=直接拒绝) | remark | create_time | update_time
```
> 无 domain / source 列。**唯一写入方 = 启动自扫描补缺**；精确权限码权威 = `sql/iam.sql` 种子，扫描不回写、不剪除。页面只读无 CRUD。

### oauth2_registered_client — 客户端注册

```text
id | client_id | client_secret (BCrypt) | client_name | client_authentication_methods
authorization_grant_types | redirect_uris | post_logout_redirect_uris
scopes   ← 客户端持有的 scope 码 (CSV)，作客户端↔sys_scope 连接表
client_settings | token_settings
```
> Access Token 格式强制 `REFERENCE`（Opaque），Redis 撤销即失效。

## 三、字典写入语义（谁能改什么）

| 对象 | 写入方 | 页面 |
|---|---|---|
| `sys_scope` / `sys_scope_permission` | **仅 `sql/iam.sql` 种子** | 「授权范围」只读展示 |
| `sys_permission` | 种子 + 管理端 API | 「权限管理」可维护码本身 |
| `iam_endpoint_policy` | **种子 + 启动自扫描补缺** | 「资源准入」只读，无增删改 |
| `oauth2_registered_client.scopes` | 管理端 API | 「客户端管理」勾选授权范围 |
| `sys_role_permission` | 管理端 API | 「角色管理」勾选绑定 |
| 其余业务表 | 管理端 API | 对应页面 |

## 四、种子数据速查

### 默认账号

| username | 密码 | 角色 | 权限码 |
|---|---|---|---|
| `admin` | `123456` | `ADMIN` | 16 个 admin 域码 |
| `user` | `123456` | `PORTAL` | `portal:client:read` |

### 默认客户端（5 个）

| client_id | 授权模式 | scopes |
|---|---|---|
| `admin-app` | 授权码 + 刷新 | `openid,profile,read,write,admin.full` |
| `portal-app` | 授权码 + 刷新（PKCE） | `openid,profile,email,portal.profile` |
| `web-app` | 授权码 / 密码 | `openid,profile,email,read,write,third.profile` |
| `device-app` | 设备码 | `openid,profile,email,read` |
| `mobile-app` | 授权码 + PKCE | `openid,profile,email,read,write` |

> `device-app` / `mobile-app` 无业务 scope → 自省交集为空，仅能访问 OIDC 标准端点（fail-closed）。

### 权限码（17）

| ID | code | 说明 |
|---|---|---|
| 1–2 | `user:read` / `user:write` | 用户查看 / 管理 |
| 3–4 | `role:read` / `role:write` | 角色查看 / 管理 |
| 5–6 | `session:read` / `session:write` | 会话查看 / 管理 |
| 7–8 | `application:read` / `application:write` | 应用查看 / 管理 |
| 9–10 | `client:read` / `client:write` | 客户端查看 / 管理 |
| 11–12 | `permission:read` / `permission:write` | 权限码查看 / 管理 |
| 13–14 | `record:read` / `record:write` | 授权记录查看 / 清空 |
| 15–16 | `policy:read` / `policy:write` | 端点准入策略查询 / 配置 |
| 17 | `portal:client:read` | 门户「我的应用授权」查询 |

### 授权范围（3 组）

| scope | 展开码数 | 持有客户端 |
|---|---|---|
| `admin.full` | 16（admin 域全量） | `admin-app` |
| `portal.profile` | 1（`portal:client:read`） | `portal-app` |
| `third.profile` | **0**（空映射，fail-closed） | `web-app` |

## 五、新增内容的落库步骤

- **新增权限码**：`sys_permission` 加行（`remark` 带 `【管理端】`/`【门户】` 前缀）→ 按需绑角色/scope → 重载种子
- **新增受管控接口**：① 加权限码（若新码）→ ② 绑角色/scope → ③ `iam_endpoint_policy` 加端点行写入该码 → 重载 + 重启
  - 前提：控制器方法须位于 `controller.admin|portal|third` 包下，否则不入表、落认证档
- **新增客户端**：`oauth2_registered_client` 加行，或走「客户端管理」页
- **存量库升级**：执行 `sql/migration/V6.x__*.sql`，**不要**重跑基线（基线会 DROP 重建）
