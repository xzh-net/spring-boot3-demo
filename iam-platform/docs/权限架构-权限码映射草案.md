## 1. 权限码清单 (草案 16 码 → 执行版 14 码)

| code | name | 覆盖管理对象 |
|---|---|---|
| user:read | 用户查看 | 用户列表/详情/用户会话查询 |
| user:write | 用户管理 | 用户增删改、启停、重置密码、踢会话、联动清理 |
| role:read | 角色查看 | 角色列表、用户-角色查询 |
| role:write | 角色管理 | 角色增删改、用户-角色绑定 |
| session:read | 会话查看 | 在线会话/用户会话查询 |
| session:write | 会话管理 | 各维度强制下线 |
| application:read | 应用查看 | 应用列表/授权/渠道查询 |
| application:write | 应用管理 | 应用增删改、授权配置、渠道 CRUD |
| client:read | 客户端查看 | OAuth 客户端列表/详情、客户端准入策略查询 |
| client:write | 客户端管理 | 客户端 CRUD、密钥重置、客户端准入策略配置 |
| policy:read | 准入策略查看（**已废除**，端点已随准入管理页删除） | 端点准入策略列表 |
| policy:write | 准入策略管理（**已废除**，端点已随准入管理页删除） | 策略改码/停用/删除、重新扫描播种 |
| permission:read | 权限查看 | 权限码列表 |
| permission:write | 权限管理 | 权限码增删改 |
| record:read | 记录查看 | 授权记录/consent 记录查询 |
| record:write | 记录管理 | 授权记录清空 |

## 2. 端点 → 权限码完整映射 (草案 53 行 → 执行 49 行, 去 policy 组 4 行)

### user (10)
- user:read: GET /api/admin/users, GET /api/admin/users/{id}, GET /api/admin/users/{id}/sessions
- user:write: POST /api/admin/users, PUT /api/admin/users/{id}, DELETE /api/admin/users/{id},
  PUT /api/admin/users/{id}/enable, POST /api/admin/users/{id}/reset-password,
  DELETE /api/admin/users/{id}/sessions, DELETE /api/admin/users/{userCode}/data

### role (6)
- role:read: GET /api/admin/roles, GET /api/admin/user-roles/{userCode}
- role:write: POST /api/admin/roles, PUT /api/admin/roles/{id}, DELETE /api/admin/roles/{id},
  PUT /api/admin/user-roles/{userCode}

### session (5)
- session:read: GET /api/admin/sessions/online, GET /api/admin/sessions/users/{id}
- session:write: POST /api/admin/sessions/{ssoSessionId}/logout,
  DELETE /api/admin/sessions/online/{username}, POST /api/admin/sessions/users/{id}/logout

### application (11)
- application:read: GET /api/admin/applications, GET /api/admin/applications/{appId}/authorizations,
  GET /api/admin/applications/{appId}/channels
- application:write: POST /api/admin/applications, PUT /api/admin/applications/{id},
  DELETE /api/admin/applications/{id}, POST /api/admin/applications/authorizations,
  DELETE /api/admin/applications/authorizations/{id}, POST /api/admin/applications/{appId}/channels,
  PUT /api/admin/applications/{appId}/channels/{channelId},
  DELETE /api/admin/applications/{appId}/channels/{channelId}

### client (10) — 含 /api/admin/policies (客户端准入策略, AdminClientPolicyApiController)
- client:read: GET /api/admin/clients, GET /api/admin/clients/{id},
  GET /api/admin/policies, GET /api/admin/policies/{clientId}
- client:write: POST /api/admin/clients, PUT /api/admin/clients/{id}, DELETE /api/admin/clients/{id},
  POST /api/admin/clients/{id}/reset-secret, POST /api/admin/policies,
  DELETE /api/admin/policies/{clientId}

### policy (4) — **已废除**: 4 端点随准入管理页删除, policy:read/write 两码不入执行版
- policy:read: GET /api/admin/endpoint-policies
- policy:write: PUT /api/admin/endpoint-policies/{id}, DELETE /api/admin/endpoint-policies/{id},
  POST /api/admin/endpoint-policies/rescan

### permission (4)
- permission:read: GET /api/admin/permissions
- permission:write: POST /api/admin/permissions, PUT /api/admin/permissions/{id},
  DELETE /api/admin/permissions/{id}

### record (3)
- record:read: GET /api/admin/records, GET /api/admin/records/consents
- record:write: DELETE /api/admin/records

- PORTAL / THIRD_PARTY 角色 → 不绑任何权限码 (原 app:* 码已删)。
- admin 域新播种端点 → 仍落粗档 ADMIN_SERVICE_TOKEN (defaultAuthorityOf 不改),
  人工细化改码, 两档并存。
